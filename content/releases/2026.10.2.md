**Your code runs on its own.** The hidden checks in these exercises work out the right answer
for themselves, to compare it with yours. Until now your code ran in the same process as the
checks, so a submission could look up that answer instead of computing it, and pass. The
exercises above now run your code in a process of its own, as every capstone already does, so
only the work itself passes. An honest solution passes exactly as before, and nothing in the
briefs has changed. Per-user isolation keeps your code beside its checks, as they look inside
your service for traces of deleted memories, but the answer is no longer anywhere your code can
reach.

**Query rewriting needs the whole conversation.** A rewrite that sent the model only the last
message of the history could pass, because the last reply happened to name the product. It no
longer does: the conversation now moves on without naming it, so only the whole history, in
order, tells the model what "its" means.

**More mistakes caught.** Retries and backoff now has a case for a default `sleep` that returns
at once, and query rewriting for calling the model on a first question.
