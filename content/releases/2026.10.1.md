**Every check explains itself.** A failing check always told you its title; now every assertion
behind it also says what it expected, what it got and, where it can, what to look at. Nothing
about what passes has changed in those exercises.

**A few shortcuts are closed.** Some checks compared what your code returned directly, which an
object that claims to equal anything could pass. They now compare plain values, so an honest
solution passes exactly as before. Query rewriting's model now tags each rewrite, so a rewrite
worked out without asking the model no longer passes, and retries and backoff checks that the
default `sleep` really waits.

**Steadier grading.** The research team milestone checks that workers run together and that
`max_workers` is respected. On a busy grader the workers could start more than two seconds
apart, and a correct solution could fail. They now wait for each other for as long as a busy
grader needs.

**Guided projects are worth more.** Milestones before each project's capstone now earn 250 to
300 XP, in step with the work they ask for.

**Closer to practice.** The briefs on temporal edges, prompt caching and memory as a tool now say
how production systems do it: bitemporal edges, cache breakpoints, and a memory tool that edits
files.
